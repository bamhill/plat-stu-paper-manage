# 研究生论文过程管理系统

> 一个导师用来盯着学生论文进度的本地小工具。不用登录，打开浏览器就能用。

## 这玩意儿能干啥

导师日常最头疼的事：手底下几个学生，每人手里一两篇小论文在投，返修意见回来了要改，大论文开题答辩一堆日期要记。

这个系统把所有这些乱七八糟的事情装在一个地方：

- 哪个学生的论文投到哪个期刊了？一眼看到
- 审稿意见回来了，是大修还是小修？点开就有
- 返修改到第几轮了？分轮记录，附件跟着走
- 大论文开题没？答辩没？外审多少分？一个页面搞定
- 想看某个学生所有东西？点击进去全部列给你

## 三步跑起来

```bash
# 1. 装依赖
npm install

# 2. 建数据库
npx prisma db push

# 3. 灌点初始数据（刘欣雨、邱澳雪、陈儒全三位同学已经在里面了）
npx prisma db seed

# 4. 启动
npm run dev
```

浏览器打开 `http://localhost:3000` 就能看到首页了。

## 界面大概长这样

左边一排菜单，右边是内容区。

| 菜单 | 能做什么 |
|------|----------|
| 首页 | 按年级分组的学生卡片，谁在写论文、投到哪了、审稿意见回来没，一目了然 |
| 学生管理 | 增删改查，可以标记"这个学生别在首页显示了" |
| 小论文 | 论文列表，点进去能看到论文详情——投稿历程、返修记录都在里面 |
| 投稿记录 | 每次投稿记一笔，稿件编号、审稿意见、返修轮次全部展开看 |
| 返修记录 | 专门看返修的地方，可以传审稿意见附件、修改稿 |
| 大论文 | 三个外审专家分别打分，答辩成绩，开题和答辩日期 |
| 综合查询 | 搜索框一搜，按论文看还是按学生看随便切 |
| 返修分析 | 把审稿意见按实验/写作/创新/文献/图表/方法自动归类 |
| 批量导入 | 下载 Excel 模板，填好一次性导进来，不用一条条录 |
| 系统设置 | 改附件存哪、加学位类型、调首页显示哪些状态的论文 |

## 文件存在哪

所有数据都在 `data/` 目录下：

- `data/dev.db` — 数据库（一个文件，备份直接复制它就行）
- `data/files/` — 上传的附件（按学生名字自动分文件夹）
- `data/config.json` — 系统设置（改过的设置都在这儿）

## 注意事项

- 这是本地单人用的，别部署到公网上去
- 没有登录功能，谁打开浏览器都能看
- 附件目录可以在设置里改成别的路径（比如 `D:\研究生管理\`）
- 数据库备份直接复制 `data/dev.db`，想恢复覆盖回去就行
- 如果数据库搞坏了：`npx prisma db push --force-reset && npx prisma db seed`
