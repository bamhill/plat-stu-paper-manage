# 返修意见整理分析功能 — 设计文档

**日期**: 2026-05-13
**状态**: 已确认

## 定位

为导师提供审稿意见的检索分析和 AI 自动归类功能。新增 `/analysis` 页面。

## 功能模块

### 模块一：检索与筛选

- 筛选条件：学生、期刊/会议名、时间区间（from/to）、返修类型（minor/major/resubmit）
- 结果：审稿意见卡片列表，每条展示学生名、论文标题、期刊、返修类型、收到日期、意见摘要
- 点击可跳转到对应投稿详情

### 模块二：AI 智能分析

- 用户从筛选结果中勾选一批审稿意见 → 点击"AI分析"
- 系统将选中意见发送给分析引擎
- 返回分类结果：按问题类型分组的统计 + 具体问题摘要
- 问题类型：实验不充分、写作问题、创新性不足、文献综述不足、图表质量、其他

### AI 配置（Settings 页面新增）

- AI 模式：关闭 / 本地规则引擎 / Cloud API
- API Key（Cloud API 模式时显示）
- API 地址（Cloud API 模式时显示，默认 `https://api.deepseek.com/v1`）
- 模型名称（默认 `deepseek-chat`）

## 本地规则引擎

基于中文关键词匹配：
- "实验""对比""baseline""数据" → 实验不充分
- "写作""语法""表达""语言" → 写作问题
- "创新""novelty""贡献" → 创新性不足
- "文献""综述""related work" → 文献综述不足
- "图表""figure""table" → 图表质量

将审稿意见分段，匹配关键词，归类统计。

## Cloud API

使用 OpenAI 兼容接口调用（默认 DeepSeek API）。
Prompt 模板：将选中的审稿意见列表发送给 LLM，要求按预设类型分类并返回 JSON 格式结果。
